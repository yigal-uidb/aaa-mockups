# AAA mockups

סרטוני הדגמה ומוקאפים של AAA.

| תיקייה | מה יש בה |
|---|---|
| `emek-yizrael-video/` | סרטון ההדגמה למועצה אזורית עמק יזרעאל: פרויקט Remotion, צילומי המסך, התסריט והמוזיקה. |
| `herzliya-video/`, `aaa-demo-herzliya/` | אותו סרטון לעיריית הרצליה: אותו תוכן, עם השמות של העירייה ושכונות העיר. |
| `aaa-demo/` | מה שצריך כדי לצלם מחדש: אפליקציית "פניות תושבים" של המועצה, נתוני הדוגמה, שרת ההדגמה עם המודל המתוסרט, וסקריפט הצילום. |

## הערות
